# Refúgio Sattva

Site do Refúgio Sattva: chalés com vista para o mar na Praia da Solidão, Florianópolis (SC).

Feito com React, Vite, Tailwind CSS e shadcn/ui.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```

Os arquivos finais ficam em `dist/`.

## Onde editar

- Textos, fotos e links de reserva: `src/data/content.ts`
- Cores e fontes: `src/index.css`
- Título, descrição para o Google e dados estruturados: `index.html`
- Notas de SEO e fotos: `TEXTOS-SEO.md`
